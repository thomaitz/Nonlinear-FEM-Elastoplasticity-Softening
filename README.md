# Extended Methods for Finite Element Modeling

Python implementation of nonlinear finite element modeling focusing on **elastoplasticity with softening** (`simplified_plasticity_softening_code.ipynb`).

## Overview
This repository contains a finite element solver written from scratch in Python to simulate nonlinear material behavior beyond the elastic limit, including strain softening. Developed as part of advanced solid mechanics coursework (STRAINS Master's program).

## Key Features
- Custom finite element formulation and global stiffness assembly in Python
- Nonlinear constitutive modeling with elastoplastic yielding and softening behavior
- Incremental-iterative solution procedure and stress–strain / load–displacement response visualization

## How to Run
1. Clone the repository or open `simplified_plasticity_softening_code.ipynb` directly in Jupyter Notebook / Google Colab.
2. Ensure standard scientific Python libraries are installed (`numpy`, `matplotlib`).
3. Run all cells sequentially to reproduce the numerical simulation and plots.
